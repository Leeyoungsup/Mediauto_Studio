# 계정 가입과 기관 관리자 검토

기존 `auth_users`, 비밀번호 해시 함수, 세션, 조직·역할 검증을 사용한다. 기존 임상 등록 중복 방지 모델과 가입 신청을 다른 테이블과 모델로 관리한다. 자동 가입 권한 부여는 기관 검토 기준이 합의되기 전까지 사용하지 않는다.

## 사용 방법

1. 신청자는 로그인 화면의 **Request an Account**에서 기관 코드·이름·사용자명·비밀번호를 입력하고 **Submit Registration Request**를 누른다. 이때 표시되는 **Registration Confirmation Code**를 기관에서 평소 사용하는 연락 경로로 관리자에게 전달한다.
2. 해당 기관 관리자는 **Settings → Accounts → Pending**에서 이름과 사용자명을 대조한 뒤 **Review**를 연다. **Account Role**과 **Applicant Confirmation Code**를 입력하고 **Approve Account**를 누른다. 역할은 Pathologist, Slide Registration Staff, Viewer 중 선택한다. **Reject Request**로 반려할 수 있다.
3. 승인된 신청자는 처음 입력한 자격 증명으로 로그인한다. **Reviewed**에는 승인·반려 상태, 역할, 검토 시각이 남으며 DB에는 검토자 ID도 기록한다. 반려 후 다시 신청할 수 있다.

코드는 신청자와 관리자가 동일 신청을 대조하기 위한 값이다. 연락처나 소속 확인은 관리자가 수행한다. 이메일 전송이나 비밀번호 재설정은 별도 범위다. 활성 관리자가 있는 기관에서만 대기 신청이 생성되며, 공개 응답으로 기존 계정과 미설정 기관의 존재 여부를 조회할 수 없다. 동일한 대기 신청의 비밀번호로 재제출하면 기존 확인 코드를 다시 표시한다.

## 저장과 롤백

- `0027_registration_requests`가 추가 전용으로 소급 변경 없는 가입 신청 테이블·대기 유일 인덱스·상태 제약을 만든다. 대기 중에는 기존 로그인과 동일한 형식의 비밀번호 해시를 저장한다. 승인 또는 반려가 끝나면 신청 테이블에서 해시를 지우며 승인 시 계정과 감사 상태를 한 트랜잭션에 저장한다.
- 같은 기관·사용자명의 대기 신청을 최대 한 건 유지한다. 승인 동시 요청은 행 잠금으로 처리한다. 일반 사용자·다른 기관 관리자는 신청을 승인할 수 없다.
- 개발 DB에는 적용 전 백업을 확보한다. 빈 가입 테이블은 `alembic downgrade 0026_related_case_links`로 되돌릴 수 있다. 신청 기록이 있으면 다운그레이드가 중단된다. 이 경우 새 테이블을 보존하고 이전 코드를 실행하는 방식으로 복귀하며, 이미 승인된 계정은 기존 인증 절차로 관리된다.

## 검증

`MEDIAUTO_DEMO_PORT=19955 scripts/verify-integration.sh`에서 TypeScript/Vite 빌드, Alembic 검사, 백엔드 테스트 59개와 Chrome 시나리오 28개를 통과했다.

- Chrome 146, Python 3.10, Node 22.12.0, PostgreSQL 18.6에서 합성 계정만 사용했다. `node scripts/registration-browser.mjs` 실행에서 390px 가입 양식, 비밀번호 일치 검사, 확인 코드, 승인 전 로그인 거부, 관리자 승인·이력, Viewer 권한으로 로그인과 관리자 화면 차단을 확인했다.
- PostgreSQL API 회귀에서 대기 중 동시 가입, 다른 비밀번호로 코드 조회 차단, 인증 없는 큐 접근, 다른 기관 승인 거부, 관리자 역할을 포함한 승인 요청 거부, 잘못된 확인 코드, 중복 승인, 반려 후 재신청을 확인했다. 인증 요청 형식 오류 응답에 입력한 자격 증명이 포함되지 않는다.
- 격리 DB에서 `0026 → 0027 → 0026 → 0027`와 `alembic check`를 실행했다. 신청 행을 넣은 상태에서 다운그레이드가 중단되고 행이 유지됨을 확인했다. 첫 시험에서 두 모델의 클래스 이름이 충돌해 가입 API가 실패했고, 가입 모델 이름을 분리한 뒤 재검증했다.
- 9920 개발 서비스는 비공개 DB 백업 `before-registration-0027-20261125T094645.dump` 확보 후 적용했다. 적용 전후 기존 계정·케이스·스캔 건수, DB 리비전, 미인증 관리 큐 HTTP 401, 390px 가입 화면을 확인했다.
