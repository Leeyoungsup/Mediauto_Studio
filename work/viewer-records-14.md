# 14번 판독 위치와 주석

## 변경 범위

참조 PDF 36–37쪽에서 확인한 거리·주석 도구를 현재 IMS 뷰어에 연결했다. 기준 커밋 `d3741bc` 뷰어와 08번의 level-0 좌표계, OpenSlide X·Y 픽셀 크기 정보를 재사용했다. 이번 범위는 사각형 ROI와 두 점 사이의 직선 거리다.

| 기능 | 저장과 복원 |
| --- | --- |
| 판독 위치 | **위치 저장**으로 중심점과 배율을 사용자·스캔별로 저장한다. 해당 스캔을 다시 열면 복원하며, **저장 위치 복원**으로도 이동할 수 있다. 화면 크기에 따라 영상 경계에서 중심을 보정할 수 있다. |
| 사각형 ROI | 영상에서 두 모서리를 드래그하고 이름을 입력해 저장한다. 목록과 오버레이에 표시하며 **위치로 이동**으로 해당 영역을 확대한다. |
| 직선 거리 | 두 점을 드래그하고 저장한다. 서버가 `hypot(Δx × MPP X, Δy × MPP Y)`로 계산한다. 원본 두 점과 계산 당시의 MPP, 길이·단위를 함께 보관한다. 둘 중 한 축의 MPP가 없으면 픽셀 거리로 표시한다. |
| 접근과 삭제 | WSI 조회 권한을 따른다. 관리자와 담당 병리의는 주석·측정을 만들 수 있다. 작성자와 관리자는 삭제할 수 있으며 서버에 삭제 감사 이벤트를 남긴다. 판독 위치는 본인만 조회한다. |

좌표는 영상 원본의 픽셀 기준이다. NDPI와 SVS처럼 다른 원본 파일은 각각의 좌표계와 기록을 유지한다. 확대·축소나 패닝은 화면에 투영되는 위치만 바꾸며, 저장된 좌표와 거리값은 유지된다. 같은 원본의 파일 등록 화면에서 정규 케이스로 확정한 경우 같은 스캔 지문을 사용한다.

## 실행과 검증

1. 케이스의 WSI를 열고 확대하거나 드래그한 다음 **위치 저장**을 누른다.
2. **사각형 ROI** 또는 **거리 측정**을 선택해 영상 위에서 드래그한다. **주석 저장**을 누른 뒤 아래 기록 목록과 영상의 표식을 확인한다.
3. 다른 배율, 새로고침, 로그아웃 후 재로그인에서 같은 기록을 확인한다. 동일 위치는 해당 스캔을 선택하면 복원된다.
4. `scripts/verify-integration.sh`에서 PostgreSQL API 테스트와 실제 예제 NDPI·SVS Chrome 테스트를 재현한다. Playwright 의존성 경로는 10번 검증 문서와 같다.

| 기준 | 검증 |
| --- | --- |
| X·Y MPP가 다른 기준 길이 | X 0.25µm/px, Y 0.50µm/px, 차이 12px·8px에서 5.00µm |
| MPP가 빠진 기준 길이 | 차이 3px·4px에서 5.00px |
| 좌표·단위 재현 | 실제 WSI로 ROI의 원본 좌표 변환, 확대 비율과 위치 재투영, 새로고침·재로그인의 저장 좌표·거리 표시, 다른 스캔으로 전환했을 때 기록 분리를 확인 |
| 오류·권한 | 버전 충돌 409, 경계 밖·폭이 없는 ROI 422, 미배정 접근과 타인 삭제 차단, 중복 저장 방지. 브라우저에서 저장 503을 주입했을 때 초안 유지와 재시도 성공 확인 |

자동 테스트 17개와 Chrome 통합 시나리오가 통과했다. 예제 NDPI에서 같은 거리 4.03mm가 화면 확대율 변경과 재로그인 뒤에도 표시됐다. 브라우저 좌표 비교는 포인터 입력의 CSS 픽셀 정밀도를 반영했고, 저장된 중심과 원본 주석 좌표의 복원을 별도로 확인했다. 픽셀 크기 메타데이터에 따른 소프트웨어 계산을 검증했다. 실제 장비의 교정과 임상 측정 정확도는 별도 평가 항목이다.

## 배포와 롤백

`0005_viewer_records`는 `viewer_positions`, `viewer_annotations`를 추가한다. 격리 PostgreSQL에서 0004 → 0005 → 0004 → 0005를 확인했다. 롤백 전에 두 새 테이블을 백업하고 이전 코드를 적용한 뒤 `python -s -m alembic downgrade 0004_emr_lis`를 실행한다. 이전 스키마의 케이스·연동 설정과 기존 추가 전용 감사 기록은 보존된다.
