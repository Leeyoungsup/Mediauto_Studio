# 19. Worklist 고급 필터·데이터 출처·기본값 복원

PDF 14–17쪽에서 Worklist와 세부 필터, 채취일 기준 연령 상한과 빈 결과, View 저장 화면을 확인했다. 20–21쪽의 열 표시·순서와 다단계 정렬, 8절의 날짜 범위·최근 열람·기본값 복원을 함께 반영했다. 필터 조합은 AND로 구현했다. 기존 API, 기관·배정별 권한과 16번의 저장 View를 재사용했다. [참조 PDF](../reference/Techcyte_IMS_Demo_Screen_Analysis.pdf)

## 필드·출처

| 화면 항목 | 값과 동작 |
|---|---|
| 환자·검체·담당자 | 로컬 환자명, 생년월일, 성별, Local Patient ID, 연결된 외부 MRN, 검체 번호·설명, 기존 배정 정보를 사용한다. 파일 등록 환자번호는 검증되지 않은 파일 등록 값으로 표시한다. 로컬 환자번호는 MRN과 별도로 둔다. |
| 스캔·LIS 상태 | 스캔 등록 여부를 Viewable/Missing Scan/No Slides로 구분하며, 스캔이 있는 슬라이드와 없는 슬라이드를 모두 가진 케이스는 두 분류에 해당한다. LIS 상태는 해당 기관의 Case Accession에 연결되고 반영된 스냅샷에서 조회한다. 서로 다른 상태가 여러 연결에서 유효하면 충돌로 표시한다. 출처와 수신 시각을 표시한다. |
| 날짜·연령 | 접수 시각은 사용자가 입력한 accession 시각, 등록 시각은 IMS 생성 시각, 채취일은 기록된 검체 날짜 중 가장 이른 값이다. 연령은 생년월일과 그 채취일의 만 나이다. 둘 중 하나가 없거나 순서가 뒤바뀌면 연령은 비어 있다. 파일 기반 케이스의 등록일은 파일 접수 정보의 갱신 시각이다. 시각의 날짜 필터는 서울 시간대 달력 기준이다. |
| 최근 열람 | 로그인 사용자가 권한 있는 케이스 상세나 WSI에 들어간 시각을 계정별로 저장한다. 목록 선택·미리보기는 기록하지 않는다. Today/Last 2 Days/Last 7 Days는 오늘을 포함하는 서울 시간대 달력 기준이다. 이전 열람을 소급해서 채우지 않는다. 파일 케이스를 정규 등록하면 새 정규 케이스 ID에서 열람 기록을 시작한다. |
| 기타 열 | 등록된 WSI 위치, 사용 권한이 있는 케이스 요청 수, 최근 검토 메모, 데이터 출처를 연결했다. 그룹·태그·댓글은 후속 업무 모델이 생길 때 연결한다. 값 누락과 필터 결과 없음은 UI에서 따로 표시한다. |

환자 식별 문자 검색은 브라우저에서 POST 본문으로 보낸다. 환자명 또는 환자 식별자 조건을 포함한 View는 개인 View에 저장한다. 결과, 필터 후 집계와 담당자 선택지는 기존 계정의 조회 범위 안에서 계산한다. **Reapply View**는 선택 View의 조건을 다시 적용한다. **Restore Default Worklist**는 현재 필터를 지우고 사용자 기본 열·정렬을 적용한다. 저장하지 않은 사용자 기본 정렬은 시스템 기본값을 쓴다.

## 변경과 재현

- `0008_worklist_filters`는 환자 성별, 케이스 접수 시각, 검체 채취일, 사용자 기본 정렬, 사용자별 최근 열람 테이블을 추가한다. 기존 레코드에는 값을 소급 입력하지 않는다. 시행 전에 개발 DB를 백업한다. 되돌릴 때는 이전 코드와 함께 `python -s -m alembic downgrade 0007_case_requests`를 사용한다. 이 단계에서 저장한 새 필드와 열람 시각이 제거되므로 필요하면 백업에서 복원한다. 새 필터나 정렬 기준을 포함해 저장한 View를 이전 코드로 돌려쓸 경우에는 먼저 이전에 지원하던 조건으로 정리하거나 사전 백업을 사용한다.
- 커밋 범위는 `backend/app/{clinical,models,worklist,worklist_data,worklist_views}.py`, Alembic, React Worklist·Case Details와 API/브라우저 테스트다.
- **Case Details → Case and Specimen Dates**에서 권한이 있는 계정으로 날짜를 저장한다. **Worklist → More Filters**에서 기간·연령·검체·최근 열람을 선택하고 **Apply Filters**를 누른다. 조건 칩을 클릭해 해제할 수 있다. **Columns**에서 해당 열을 켜고, **Multi-Level Sort**에서 사용자 기본 정렬을 저장하거나 복원한다. **Save New View**로 저장한 뒤 다른 세션에서 설정을 복원한다.

격리 PostgreSQL 18.6, Python 3.10.20, Node 22.12.0, Chrome 146 및 합성 환자·검체를 사용한다. 실행 명령은 `MEDIAUTO_PLAYWRIGHT_MODULE=/path/to/playwright-core/index.mjs scripts/verify-integration.sh`다. 실제 병원 LIS와 대규모 케이스 성능 평가는 미실행이다.
