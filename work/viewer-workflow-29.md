# 29. 조직 정합·판독 도구·림프절 계수

## 근거와 적용 범위

- PDF 34–38쪽 화면에서 4분할과 미니맵, 측정선, 주석 목록, 림프절 Positive와 Total을 확인했다. 점·화살표·사각형·타원·자유형·브러시·Count 도구, 주석 프리셋과 이미지 내보내기, 6개 패널 및 AI 보조 정합은 발표 설명에 포함됐다. 해당 화면과 발표에서 기관의 허용 오차나 수기 집계 정책에 대한 참석자 승인 기록은 확인되지 않았다. [참조 PDF](../reference/Techcyte_IMS_Demo_Screen_Analysis.pdf)
- 현재 IMS의 판독 좌표, WSI PDF 참조를 반영한 패널, Case Logs 및 보고 버전 흐름을 확장했다. 베이스 `d3741bc`의 WSI 카메라·타일과 동일 케이스 비교 구조를 재사용했다.

## 재현 절차

1. **Multi View → Tissue Registration → Pick Tissue Landmarks**를 연다. 각 pane에 같은 조직의 첫 번째 특징점을 클릭한 뒤, 같은 방식으로 두 번째 특징점을 찍는다. 세 번째부터는 다른 조직 특징을 선택해 정합 오차를 확인한다. 최소 3쌍, 최대 8쌍을 사용한다. **Use Tissue Registration → Sync Position**을 켜면 선택한 pane의 중심과 배율이 변환된다. 현재 케이스 스캔 2–4개를 지원한다.
2. 단일 뷰에서 기존 사각형 ROI와 단일 거리 도구를 그대로 사용한다. **Additional Tool**의 **Multi-segment Distance**, **Polygon ROI**, **Point Count**는 클릭으로 점을 추가한다. **Undo Point**로 최근 점을 빼고 **Finish Points**로 완료한다. 점, 화살표, 타원과 자유곡선 브러시도 저장할 수 있다. **Save Bookmark**는 같은 계정에서 다시 열 수 있는 이름 붙은 중심과 배율을 저장한다.
3. **Calibrated ROI Preset**에서 250·500·1,000 µm 정사각형을 선택하고 중심을 찍는다. 거리와 프리셋은 원본 level-0 좌표와 축별 MPP를 사용한다. 거리 표시는 MPP가 한 축이라도 없으면 px를 사용하며, 프리셋은 두 축 모두 보정된 경우에 제공한다.
4. 영역의 **Export ROI PNG**에서 선택 ROI 윤곽과 스케일바를 각각 켜거나 끈다. 원본의 ROI 경계 상자를 최대 1,600 px로 출력한다. 스케일바는 가로 MPP를 사용하며 작은 ROI나 MPP 누락 시 스케일바를 빼거나 영역을 늘려 다시 내보낼 수 있다. 관리자는 접근 가능한 케이스를, 배정 병리의는 담당 케이스를 내보낼 수 있다. 성공·실패를 Case Logs에서 확인한다.
5. 단일 뷰의 **Lymph Node Count**에 수기 Positive·Total을 저장한다. 같은 검체의 다른 스캔에서도 같은 집계를 조회한다. 정정은 바뀐 값과 사유를 새 버전으로 남긴다. **Report Draft → Result Evidence**에서 검체별 한 계수 버전을 연결한다. 이전 보고 버전에서 사용한 값은 보존된다. 기존 Mock LIS 계약에는 보고의 승인된 본문 섹션이 포함되므로 전송할 값은 보고 본문에서 승인한다.

대응점 두 개는 좌표 변환의 이동·회전·균일 스케일을 계산하는 데 사용한다. 원본 pane 영상은 기존 방향을 유지한다. 뒤집힘, 조직 절단·변형, 픽셀 단위 영상 중첩과 자동 AI 정합의 검증은 포함되지 않는다. 설정된 대응점은 비교 세션 동안 유지한다. 림프절 집계는 수기 보조 기능이며 실제 병리과의 작업 기준과 보고 정책은 기관 검토가 필요하다.

## 마이그레이션과 검증

- `0018_viewer_workflow`는 주석 종류와 북마크 배율을 추가하고 검체별 계수 버전을 새 테이블에 저장한다. 기존 주석 좌표는 변환 없이 유지한다.
- PostgreSQL 18.6에서 `0017 → 0018 → 0017 → 0018`과 `python -s -m alembic check`를 통과했다. 확장 주석이나 계수 데이터가 생긴 DB는 다운그레이드를 차단한다. 되돌릴 때는 작업을 중지하고 확장 기록을 포함한 현재 DB를 먼저 백업한다. 배포 전 백업 복원은 기존 버전과 함께 격리 환경에서 확인하고 복원 이후 작성된 기록의 처리 방식을 별도로 결정한다.
- `MEDIAUTO_DEMO_PORT=19936 scripts/verify-integration.sh`에서 빌드, 백엔드 테스트 34개, Chrome 시나리오 16개가 통과했다. API는 다분절 MPP, PNG 메타데이터·옵션, 권한·감사, 중복·충돌, 검체의 다른 스캔에서의 정정과 보고 버전 보존을 확인한다. Chrome은 실제 NDPI·SVS에서 도형·점 계수, 북마크, 정사각형 프리셋, PNG 다운로드, 림프절 계수·보고 참조와 정합을 확인한다.
- 개발 DB를 `.runtime/before-viewer-0018-20261124T190807.dump`에 백업한 뒤 9920에 적용했다. 기존 주석·보고·동결절편 기록의 건수를 확인하고 데이터베이스 연결과 최신 프런트엔드 제공을 확인했다.
- AGENTS 명령표의 사용자 확인과 임상 검토는 대기 중이다.
