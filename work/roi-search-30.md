# 30. ROI 유사검색 어댑터

## 참조와 적용 범위

- PDF 31쪽 화면(P13 02:10)에서 ROI 미리보기, 장기계통 선택과 검색 버튼을 확인했다. 발표(T 1:02:03–1:02:28)는 외부 Aignostics 서비스로 이동하는 흐름을 설명한다. 해당 구간에서 서비스 API, 검색 성능, 기관의 외부 전송 승인에 대한 참석자 합의는 확인되지 않았다. [참조 PDF](../reference/Techcyte_IMS_Demo_Screen_Analysis.pdf)
- IMS의 기존 WSI와 저장 ROI 권한, 29번 ROI 크롭 및 카메라 복귀를 재사용했다. 베이스 저장소의 `d3741bc`를 확인했다.
- 개발 어댑터는 같은 케이스에서 사용자가 명시적으로 등록한 참조 중 동일한 장기계통을 조회한다. 256 px 이하 RGB 미리보기에서 만든 간단한 색상 히스토그램을 비교하고 최대 8건을 정렬한다. ROI의 경계 상자를 미리 본다. 점수의 임상 해석이나 진단 성능에 대한 기관 검증은 대기 중이다.

## 사용 방법

1. 관리자 또는 케이스에 배정된 병리의가 등록된 **WSI Viewer**에서 사각형·타원·다각형 ROI를 저장한다. **Review Position and Annotations → Find Similar ROIs**로 미리보기를 연다.
2. 참조로 사용할 ROI는 **Organ System → Local Reference → Save as Local Reference**로 케이스에 등록한다. 장기계통을 바꿔 저장하거나 **Remove Local Reference**로 참조 세트에서 빼도 원래 주석은 보존된다. 같은 ROI를 다시 저장하면 참조 항목을 갱신한다.
3. 검색할 별도 ROI에서 장기계통을 고르고 **Search Similar ROIs**를 누른다. 선택 ROI 자체는 결과에서 제외한다. 결과가 없으면 해당 장기계통의 빈 상태를 표시한다. 오류가 나면 같은 조건으로 재시도한다. 미리보기 재시도는 별도 버튼으로 실행한다.
4. **Open Match in WSI**에서 대상 스캔과 ROI 중심을 연다. **Back to Source ROI**로 원래 스캔과 ROI 위치에 돌아간다. 연결된 ROI를 삭제한 경우 슬라이드는 열리고 링크 상태를 표시한다.

## 권한·데이터·운영

- 검색, 미리보기와 등록 API는 관리자 및 배정 병리의에 한정한다. 소속 기관, 케이스, 스캔 권한과 ROI 원본 파일 식별자를 서버에서 검사한다. 타 케이스·삭제 주석·QC 차단 스캔을 후보에서 제외하며, 결과 링크도 기존 WSI 접근 제어를 사용한다.
- 로컬 참조 레지스트리는 기존 설정 데이터에 케이스별 최대 64개 항목을 저장한다. 항목에는 ROI 키, 스캔 키, 장기계통, 개발 어댑터 버전과 히스토그램만 기록한다. 원본 ROI 이미지, 환자 및 임상 기록, 라벨 이미지는 이 레지스트리에 저장되지 않는다. 웹 응답은 비공개 캐시 정책을 적용한다.
- 어댑터 경계에는 로컬 256 px 이하 크롭, 장기계통과 검색마다 부여하는 참조 토큰·히스토그램을 전달한다. 외부 전송 경로가 없는 개발 구현이다. 기관의 승인된 제공자·데이터 범위·목적·인증·보관 조건과 실제 전송 검증이 확보된 뒤 실서비스 계약을 검토할 수 있다.
- **Case Logs**의 `roi_similarity`에서 검색 성공·실패·거부와 참조 등록·제거를 조회한다. 감사 기록에는 ROI 본문이나 환자 정보 대신 기존 케이스·사용자·ROI 키와 결과를 남긴다.
- 새 테이블이나 마이그레이션이 필요 없다. 이전 버전으로 배포를 되돌릴 경우 참조 목록은 DB에 보존된다.

## 검증

- PostgreSQL 18.6, Python 3.10.20, Node 22.12.0, Chrome 146에서 검증했다.
- `MEDIAUTO_DEMO_PORT=19938 scripts/verify-integration.sh`에서 빌드, 백엔드 테스트 35개와 Chrome 시나리오 17개를 통과했다. API 계약 테스트는 합성 이미지로 색상 순위, 장기계통 필터, 빈 결과, 일시적 어댑터 장애, 파일과 ROI 불일치, 같은 기관의 다른 케이스 격리, 삭제·제거, 접근 거부와 Case Logs를 확인한다.
- 9920 개발 서버에서 DB 연결, 최신 UI 번들, 인증이 필요한 새 API, 없는 스캔의 404 응답을 확인했다.
- 브라우저 검사는 로컬 예제 NDPI·SVS와 저장 ROI로 실제 미리보기 로딩·실패 복구, 장기계통, 결과 탐색과 원본 위치 복귀를 확인한다. 기관 연동·임상 사용 검증과 AGENTS 명령표 사용자 확인은 대기 중이다.
