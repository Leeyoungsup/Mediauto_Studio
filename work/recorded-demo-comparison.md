## 재현

- Case Details에서 **Open Viewer**를 클릭한다. **Sort Tray**를 바꿔 Gallery와 이전·다음 버튼의 순서를 확인한다. **Viewer Settings → Save as Default**를 사용한 뒤 새 세션에서 복원 여부를 확인한다.
- **Present Slide**를 클릭한다. Case ID, Scan Label과 문서 탭이 숨겨지고 영상, 확대·축소와 스케일바가 표시된다. **Exit Presentation** 또는 Escape로 같은 스캔의 판독으로 돌아온다.
- 슬라이드에서 저장 주석을 추가한 뒤 **Export Current View**를 누른다. 주석과 스케일바를 켜고 끈다. 미리보기 배율·형식·크기를 바꿔 다운로드한다. **Case Logs → Exported Current View**에서 내보내기 로그를 확인한다.
- 스캔이 6장 이상인 같은 케이스에서 **Multi View**를 열어 6장을 선택한다. 7번째 선택 제한, 활성 pane, **Sync Position**, 단일 화면 복귀를 확인한다.

## 검증 기록

- 환경 · 기존 Mediauto Studio Conda, PostgreSQL 18 격리 DB, Node 22.12.0, Chromium, 합성 케이스와 NDPI·SVS. Alembic 스키마 변경 없음. Viewer 정렬 기본값은 기존 사용자별 JSON 설정에 저장한다.
- `npm --prefix frontend run build` · PASS. Vite의 번들 크기 경고가 남아 있다. `git diff --check` · PASS.
- `scripts/verify-integration.sh --manual`로 격리 환경을 기동한 뒤 `node scripts/viewer-records-browser.mjs` · PASS. 저장 주석 포함과 제외 미리보기, 300% 확대, 절반 해상도의 JPEG 다운로드, Case Logs 기록, 기존 저장 위치와 좌표 재접속 복원을 검증했다.
- `node scripts/viewer-preferences-browser.mjs` · PASS. Tray 정렬의 새 세션 복원과 발표 모드에서 식별정보·라벨·문서 탭 가림, Zoom, Escape 복귀를 검증했다.
- `node scripts/multi-view-browser.mjs` · PASS. 4개 고유 SVS와 그중 1개의 별도 테스트 pane 2개로 6개 표시, 7번째 제한, 로딩 오류 복구, 활성 pane, 5개 상대 pane의 좌표·배율 명령 전달을 검증했다. 이 테스트의 좌표 잔차는 동기화 계산의 결과이며 조직 정합 정확도는 여기에서 측정하지 않았다.
- HTTPS 9920 배포 확인 · PASS. 서버에서 Chromium으로 Tray 정렬 선택, 내보내기 미리보기, 발표 모드 진입·복귀와 한 케이스의 서로 다른 스캔 5개 로딩을 확인했다. 6개 경로와 7번째 제한은 위 격리 브라우저 결과를 사용한다.
