# 15번 Multi View 검증

## 구현과 사용

참조 PDF 34쪽에서 확인된 화면은 4분할이었다. 발표자는 최대 6분할과 정합 지원을 설명했다. IMS에서는 기준 커밋 `d3741bc`의 같은 케이스 선택, 최대 네 개의 Canvas 뷰어, 활성 패널과 확대 구조를 현재 React 뷰어에 연결했다. 배율과 중심점을 연결하는 동기화는 IMS에서 추가했다.

1. 케이스의 WSI 뷰어에서 **Multi View**를 연다. 현재 스캔과 같은 케이스의 다른 스캔 하나가 초기 선택된다. 상단에서 2~4개의 스캔을 선택한다.
2. 패널을 누르거나 키보드 포커스를 이동해 활성 화면을 바꾼다. **위치 동기화**가 켜져 있으면 현재 조작 중인 화면의 중심 위치와 상대 배율을 다른 선택 화면에 적용한다.
3. 수동으로 맞출 경우 동기화를 끄고 각 화면에서 같은 특징점을 화면 중앙에 둔다. **현재 위치를 기준점으로**를 누르고 동기화를 켠다.
4. **활성 화면 확대**는 다른 패널을 숨기고 동기화를 일시 중지한다. **분할 화면 복원** 후 다음 조작부터 동기화를 재개한다. **활성 스캔 단일 뷰**로 ROI 편집·기록 목록·판독 위치 저장 및 검토 작업을 이어갈 수 있다.

| 지원과 제한 | 동작 |
| --- | --- |
| 화면 수 | 같은 케이스의 기존 등록 스캔 2~4개. 다섯 번째 선택이 비활성화된다. 작은 화면은 한 열로 쌓인다. |
| 위치·배율 | 영상 폭·높이에 대한 정규화 중심 좌표와 화면 맞춤 배율의 비율을 전달한다. 수동 기준점 사용 시 각 기준점에 대한 정규화 이동량과 기준 배율 비율을 전달한다. 영상 경계나 배율 한계에 도달하면 스캔별로 보정한다. |
| 화면 확대와 전환 | 활성 패널을 크게 보는 동안 다른 패널 상태를 보관한다. 비교 세션의 선택·동기화·수동 기준점은 저장하지 않는다. |
| 영상 정합 | 수동 기준점 한 쌍은 이동 오프셋과 상대 배율을 맞춘다. 회전·뒤집기·국소 변형의 자동 보정은 제공하지 않는다. |
| 시각화와 자원 | 패널별 미니맵·스케일바·기존 영상 오버레이를 유지한다. 비교 모드에서 패널별 타일 동시 요청은 2개, 디코드 타일 캐시는 24개로 제한한다. |
| 오류와 권한 | 기존 WSI 인증 경로를 재사용한다. 한 패널의 로딩 오류는 해당 패널에서 재시도한다. 선택한 모든 패널의 영상 정보가 있어야 동기화를 시작한다. |

동기화 오차는 구현의 좌표 전달 정확도다. 조직 대응의 정확도는 아래 측정으로 따로 기록했다.

## 샘플별 조직 특징점 오차

사람이 짚은 조직의 거친 모양을 사용한 탐색적 점검이다. 각 영상의 최하위 피라미드를 WSI 전체 좌표에 맞춰 600 × 600 기준으로 정규화했다. 첫 쌍 A를 이동 기준점으로 사용했고, 나머지 B–D 세 쌍에서 목표 영상의 X·Y MPP를 적용한 평면 잔차를 계산했다. 같은 특징점의 판독 정답이나 기관 허용 기준은 확보되지 않았다.

### 측정 재현

아래 좌표는 각각 600 × 600 정규화 프레임에서 (x, y) 순서다. 00194의 A는 중앙 작은 원형 구조, B는 왼쪽 타원형 구조, C는 중앙 오른쪽 삼각형 구조의 꼭짓점, D는 아래쪽 타원형 구조다. 04364의 A–D는 위에서 아래로 나열한 비교 가능한 조직 조각의 중심이다.

| 스캔 | A | B | C | D | 원본 폭 × 높이 | MPP X / Y |
| --- | --- | --- | --- | --- | --- | --- |
| HR SVS | 227,251 | 132,226 | 249,271 | 203,425 | 117836 × 82278 | .262583 / .262583 |
| KI SVS | 325,251 | 196,217 | 367,270 | 280,425 | 87127 × 82682 | .262583 / .262583 |
| PR SVS | 324,249 | 193,219 | 359,267 | 284,424 | 85106 × 82076 | .262583 / .262583 |
| TP SVS | 323,238 | 188,221 | 365,254 | 299,413 | 79651 × 82884 | .262583 / .262583 |
| PD NDPI | 270,74 | 304,154 | 309,248 | 333,300 | 49920 × 59904 | .229689689 / .229731903 |
| PD SVS | 86,53 | 105,100 | 111,156 | 125,187 | 70685 × 87947 | .263526 / .263526 |

정렬 전에는 출발점의 정규화 좌표를 그대로 목표에 투영한다. 정렬 후에는 `목표 A − 출발 A` 이동량을 출발점에 더한다. 투영점과 목표점의 축별 차이에 `목표 원본 축 길이 × 해당 MPP / 600 / 1000`을 곱해 mm로 변환한다. B–D 거리의 제곱평균제곱근과 최대값을 위 표에 기록했다. 확대된 저해상도 사진에서 직접 고른 점이므로 원본 세포 단위 비교나 임상 정합 판정에는 별도 검증이 필요하다.

이 단계는 기존 WSI 읽기 경로를 사용하며 DB 마이그레이션이 필요 없다.
